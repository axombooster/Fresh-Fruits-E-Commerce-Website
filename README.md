# 🍎 Fresh Fruits E-Commerce Website (Frontend)

A modern and fully responsive **Fresh Fruits E-Commerce Website** built using **HTML, CSS, and JavaScript**.
This project focuses on **frontend UI/UX and client-side logic only** and is ideal for learning, portfolio showcase, and demos.

---

## 🚀 Project Overview

This project showcases a real-world styled e-commerce website for a fruits & grocery store.
It includes product listings, shopping cart functionality, a multi-step checkout flow, and payment method UI — all handled on the frontend.

> ⚠ **Note:** This is a frontend-only project. No backend or server-side functionality is used.

---

## ✨ Features

* Modern & clean UI/UX design
* Fully responsive (Desktop, Tablet & Mobile)
* Product listing with ratings & badges
* Add to Cart functionality
* Cart sidebar with quantity control
* Cart data stored using `localStorage`
* Multi-step checkout process
* Payment method selection UI:

  * UPI
  * Credit / Debit Card
  * Cash on Delivery
* Order summary & confirmation modal
* Smooth animations & scroll effects
* Newsletter & contact form (frontend simulation)

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & responsive layout
* **JavaScript (Vanilla JS)** – Interactivity & logic
